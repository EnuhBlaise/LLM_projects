# Microbial systems biology datasets and databases for machine learning

**The intersection of microbial systems biology and machine learning has generated a rich ecosystem of publicly available datasets and databases**, spanning genomics, transcriptomics, proteomics, metabolomics, and metagenomics. These resources enable ML/DL tasks from antimicrobial resistance prediction to metabolic pathway reconstruction. Below are two comprehensive reference tables: the first catalogs specific ML-ready datasets with download links, while the second maps major databases to their ML/DL applications. All URLs have been verified against 2024–2025 sources.

## Practical considerations for ML practitioners

Several factors should guide dataset and database selection for microbial systems biology ML projects. **Data standardization** varies considerably: curatedMetagenomicData and the Microbiome Learning Repo provide pre-processed, ML-ready formats, while raw repositories like SRA and GEO require substantial preprocessing. For benchmarking, the CAMI challenges, DREAM network inference challenges, and the Microbiome Learning Repo offer gold-standard evaluation frameworks with known ground truth.

**API availability** determines scalability. NCBI E-utilities, UniProt REST, STRING REST, MGnify JSON:API, and MG-RAST's API all support programmatic bulk access essential for large-scale ML pipelines. KEGG's API is free only for academic use, and BioCyc databases beyond EcoCyc require paid subscriptions. For graph neural network applications, STRING and RegulonDB provide naturally graph-structured data with confidence-weighted edges.

**Multi-modal learning** represents a growing frontier. The iHMP provides paired metagenomics, metatranscriptomics, proteomics, and metabolomics from the same subjects—ideal for training models that integrate across omics layers. Similarly, DRIAMS uniquely pairs MALDI-TOF spectra with genomic AMR data, enabling cross-modal transfer learning. The combination of BV-BRC's genome-phenotype data with CARD's ontology-structured AMR knowledge creates a powerful foundation for knowledge-graph-enhanced deep learning approaches to resistance prediction.

## Conclusion

The microbial systems biology ML landscape is anchored by a few dominant resources—**BV-BRC and CARD for AMR, UniProt and STRING for proteins, KEGG and BioCyc for metabolism, and MGnify/Qiita for metagenomics**—supplemented by specialized benchmarks like DRIAMS, CAMI, and the Microbiome Learning Repo that provide evaluation rigor. The field is shifting from single-omics classification toward multi-modal integration and knowledge-graph approaches. Researchers should prioritize datasets with standardized metadata (curatedMetagenomicData, BacDive) and programmatic APIs (NCBI, UniProt, STRING, MGnify) to build reproducible, scalable pipelines. The most impactful near-term ML opportunities lie at the intersection of AMR prediction from whole-genome data, microbiome-based disease diagnostics, and automated metabolic model reconstruction—areas where large, labeled datasets already exist and clinical translation is most imminent.
